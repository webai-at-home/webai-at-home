WebGPU experiments / issue #207

Gemma 4 E2B
on hand-written WebGPU compute kernels

No ONNX Runtime Web, no Transformers.js, and no LiteRT.js. The page holds the WebGPU Shading Language compute kernels itself and talks to the graphics processor directly. This is the floor every other measurement of the same weights is compared against.

Step 1 — Load the model

The first load downloads about 2.5 gigabytes of weights from Hugging Face and writes them to a WebGPU device. The browser caches them, so later loads skip the download.
