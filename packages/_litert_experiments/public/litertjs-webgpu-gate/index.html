Milestone zero of issue #179. This page asks one question: does @litertjs/core load a .tflite graph and compile it for WebGPU in this browser? It runs one trivial graph, a single linear layer whose input and output both have the shape of a shard boundary, and compares the result against the output PyTorch produced for the same input.

The graphs are generated artifacts and are not committed. Write them first with tools/trivial_shard_export/export_trivial_graph.py.
