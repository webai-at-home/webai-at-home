Prefill at fixed prompt lengths

Milestone five of issue #179. Static shapes mean one exported signature per prompt length, so a prompt of 32 tokens and a prompt of 128 tokens are two different graphs of the same weights. This page runs each of them and measures what reading a whole prompt in one call is worth against reading it one token at a time.

Prefill turns out to be simpler than decode rather than harder, because it starts at position 0: there is no cache to read and no position to write at, so a prefill graph takes only the hidden states, the rotary tables, and a causal mask, and returns its own keys and values followed by zeros. The cache it writes has exactly the shape a decode graph reads.

The last part answers the other question milestone five asks: whether sending one long activation beats sending several short ones, measured over the same WebSocket relay milestone four used.

Reads its graphs from /qwen3-litert-shards/models, written by tools/qwen3_prefill_export/.
