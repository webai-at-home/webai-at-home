A converted expert block through a MatMulNBits graph — issue #169 milestone 5

Milestone 0 proved that ONNX Runtime Web executes MatMulNBits against a WebGPU buffer this project owns, using weights this page invented. Milestone 3 then wrote 15.61 gigabytes of real weights to disk in a layout of its own choosing, with the scales at half precision. Nothing has yet checked that those two things fit together.

This page asks that question, and only that question: does ONNX Runtime Web compute the right expert output from the exact bytes the conversion pipeline wrote, read from a WebGPU buffer, with the scales at half precision and one zero point for every block?

It reads one real converted block of allenai/OLMoE-1B-7B-0924, and compares against an answer computed on the processor side from the same block's own bytes. Both files are generated — see the tools README for the one command that writes them.
