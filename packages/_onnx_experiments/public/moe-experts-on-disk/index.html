A mixture of experts generating with its weights on disk — issue #169 milestone 6

This is the deliverable of issue #168: a model larger than the machine's graphics memory, generating text in a browser, with the weights that are not being used kept on disk.

Qwen3-30B-A3B is 30.5 billion parameters. Converted, its 6144 experts come to 15.61 gigabytes and its always-resident part to a further 5.16. This machine has 16 gigabytes of memory in total. It generates anyway, because at any moment only 8 experts of each of the 48 layers are needed.

The same page runs each model under the three storage classes that can hold it, and draws the curve issue #168 asks for: weights in graphics memory, weights in main memory, and weights on disk in browser persistent storage. A line that stops is a storage class that cannot hold the model, and where each line stops is the point of the whole picture.

The artifacts are generated and are served by the development server from wherever they were written. See the tools README for the commands that write them. The expert blocks are copied once into the Origin Private File System and kept.
