Gemma 4 E2B JSON Schema measurement — issue #219 milestone 6

Loads the exact pinned export the real stage helper runs (onnx-community/gemma-4-E2B-it-ONNX, revision 9f4bef82ea6e296bc69f8a2f5939f73af81b07a6, q4f16, WebGPU only) and answers the question milestone 6 of issue #219 rests on: can a logits mask hold this model to a JSON Schema — the keys it requires, the types it declares, the values it enumerates — and at what price?

Milestone 0 already measured the thing underneath: a mask handed to the pipeline call decides which token this model writes, and cost 44.7 milliseconds per token. That says nothing about a schema. A key is written a token at a time and this tokenizer merges characters, so holding the model to the key capital means masking down to the entries whose text carries that key on from wherever it has got to. And a schema state carries which keys have been written and how far into one the model is, so a run reaches many more distinct states than the eight milestone 0 measured, each one scanning the whole vocabulary once.

Every schema below asks for something the question alone would not produce — a key the question never mentions, an integer where the question asked for words, a value from an enumeration the question never names — so an answer that satisfies the schema is an answer the mask decided rather than one the model happened to write.
