Why this tab is playing a quiet sound ?

A browser tab hidden in the background runs its language model several times slower, unless the browser still counts that tab as playing audio. The quiet tone, started with the Start quiet tone button, is a tone too faint to hear, played only so this tab keeps its full speed while it works in the background.

What does "Full power" mean ?

This tab is at full power once both the quiet tone is playing and the screen wake lock is held. Without both, the browser slows this tab's language model down several times once the tab is hidden or the screen locks. The Start full power button in the navigation bar turns the quiet tone and the screen wake lock on together, so this tab keeps its full speed while it works in the background.
